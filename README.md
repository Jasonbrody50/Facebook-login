Facebook Front Page Clone

A responsive Facebook landing page clone built using HTML and CSS. This project recreates the front-page layout and styling of Facebook, focusing on clean UI design, responsive structure, and modern front-end development practices.

Features
Responsive design
Clean and modern UI
Facebook-inspired layout
Structured HTML5 markup
CSS styling and positioning
Technologies Used
HTML5
CSS3
Purpose

This project was created to improve front-end development skills by practicing webpage structuring, styling, layout design, and responsiveness.
